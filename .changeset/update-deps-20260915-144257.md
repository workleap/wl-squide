Updated dependencies to their latest versions.

`@squide/firefly-webpack-configs` is bumped as a `minor` because its `webpack-dev-server` peer dependency range moved from `^5.2.4` to `^6.0.0`, which requires consumers to upgrade.

`@squide/firefly-rsbuild-configs` and `@squide/firefly-webpack-configs` no longer derive their package directory with `new URL(".", import.meta.url)`. Rslib 1.0 rewrites `new URL(..., import.meta.url)` into an asset reference, which made the Module Federation runtime plugin paths resolve to `dist/static/assets/index.ts/` and broke consumer builds.

Updated dependencies to their latest versions.

`@squide/firefly-webpack-configs` now requires `webpack-dev-server` `^6.0.0` as a peer dependency, up from `^5.2.4`. Consumers still on `webpack-dev-server` 5 must upgrade.

`@squide/firefly-rsbuild-configs` and `@squide/firefly-webpack-configs` now derive their package directory with `path.dirname(url.fileURLToPath(import.meta.url))` instead of `new URL(".", import.meta.url)`. Rslib 1.0 treats `new URL(..., import.meta.url)` as an asset reference and rewrote the specifier to an emitted asset path, which made the bundled Module Federation runtime plugins unresolvable from consuming applications.
